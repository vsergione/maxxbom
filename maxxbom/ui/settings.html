Plugin Settings

Data sources

Searches products and checks codes. Free edit mode allows arbitrary rule values and turns data source calls off. Offer lines use this same data source when its adapter can read and update them.

Quotation units

Export quantities are converted to this unit. The SketchUp model unit stays as drawn. Piece length, width and thickness stay in the model unit. Rounding steps are in this unit.

Unit mapping

Quantity kind stays fixed: pieces, area, length, volume, custom. External unit is written on BOM export and matched when offer lines are loaded. Changing the quotation unit updates area, length and volume names, and the accepted catalog names, while each one is still a standard set (m2, sq ft, …). A custom name or a custom accepted list is kept. Also accepted lists extra catalog names, separated by commas.

Development

Status and log dock on the rules window and the export dialog. Reload stays available.

Data sources

A data source is a named setup of a plugin installed on the Plugins tab. You can add more than one of the same plugin. Click a card to set it up.

Installed plugins

A FileMaker connection from an earlier version is still stored. Load the FileMaker plugin to keep using it.

Load installs a plugin so it can be used as a data source. It does not create one. Removing a plugin also removes its data sources. The CSV adapter stays installed.
