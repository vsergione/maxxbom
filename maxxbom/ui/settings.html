Plugin Settings

Editing mode

Allows arbitrary attribute values. API adapter operations are disabled in this mode.

Quotation units

Export quantities are converted to this unit. The SketchUp model unit stays as drawn. Piece length, width and thickness stay in the model unit. Rounding steps are in this unit.

Unit mapping

Plugin units stay fixed. External unit is written on BOM export and matched when offer lines are loaded. Changing the quotation unit updates length, area and volume names while they are still a standard name (m2, cm, ft2, …). A custom name is kept. Also accepted lists extra catalog names, separated by commas.
